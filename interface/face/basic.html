    Technical details
    • One product: the web and the app load the same face.js and face_world.js and draw the same frames.
    • The map is one preceptoros.bubble/1 frame and your state is another, each under 1,024 bytes: deterministic, no network, no clock. The state sits in this page as JSON (#packet).
    • Distance and time are counted in tiles and steps, never minutes: real time is NO_DATA because no clock is read. The walk advances one step every few screen frames.
    • For agents: window.preceptorFace.state() reads the screen; act(name) drives it. Actions: start, follow, up, down, left, right, whole, sound, read, say.
    • Vibration: NO_DATA.
    • Benchmarks and server deployment live in the repositories: the deployment guide of the web and the lab. Nothing on this page is measured live.
