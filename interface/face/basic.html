    Technical details
    • One product: the web and the app load the same face.js and draw the same frames.
    • Every screen is one preceptoros.bubble/1 frame under 1,024 bytes: deterministic, no network, no clock. It sits in this page as JSON (#packet) and in the Machine view.
    • For agents: window.preceptorFace.state() reads the screen; act(name) drives it. Actions: left, right, ask, home, star1 to star4, sound, read, say.
    • Vibration: NO_DATA.
    • Benchmarks and server deployment live in the repositories: the deployment guide of the web and the lab. Nothing on this page is measured live: what is not measured says NO_DATA.
