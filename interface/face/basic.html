Technical details

        

      • One product: the web and the app load the same face files and draw the same frames.
        • 

      • The map is one isometric plane drawn from small preceptoros.bubble/1 frames, each under 1,024 bytes; your state and the battle are frames too. Deterministic, no network, no clock. The state sits in this page as JSON (#packet).
        • 

      • Distance and time are counted in cells and steps; real time is NO_DATA because no clock is read.
        • 

      • Battle: the canon seeded rounds; the receipt is at most 200 bytes and is checked by replaying from tick 0. Formation changes how the squad stands, not the rounds.
        • 

      • For agents: window.preceptorFace.state() reads the screen; act(name) drives it. Actions: task, accept, decline, start, follow, up, down, left, right, whole, sound, read, say.
      • The three map icons say their name on the map when tapped, and the voice speaks it when Sound is on.
        • 

      • Vibration: NO_DATA.
