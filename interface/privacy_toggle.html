Privacy Toggle

Visual spec, four states. Static mock: every counter below is rendered from the payload shown beside it, exactly as the endpoint returned it. The interface never counts anything itself.

1 · On, findings

Redaction on 4 redacted
  • API_KEY2
  • HOME_PATH1
  • PRIVATE_IP1

Nothing above is the matched text. Class and quantity only.

{
  "estado": "ok",
  "hallazgos": [
    {"policy": "API_KEY",    "count": 2},
    {"policy": "HOME_PATH",  "count": 1},
    {"policy": "PRIVATE_IP", "count": 1}
  ]
}

2 · Off

Redaction off Text leaves as typed

No counter is shown, because none was produced. An empty list here would read as “nothing found”, and nothing was looked for. 

(no call is made)

3 · On, nothing found

Redaction on Nothing redacted

Nothing redacted — the text was already clean.

Declared, never blank. A silent panel looks the same whether the filter ran and found nothing or never ran at all. 

{
  "estado": "ok",
  "hallazgos": []
}

4 · Error, fail-closed

Redaction on Send blocked

The filter could not finish, so nothing was sent.

The send button stays disabled until the filter runs clean. No retry without it, no “send anyway”: a failed filter is not the same as a clean text, and the interface never lets the two look alike. 

(no payload: the call raised, no text was returned)
