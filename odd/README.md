# odd/ — Organic Driven Development

The law lives in `study` → `02-legislation.md` (Amendment · ODD routing ·
2026-10-28). Operating manual of the house (canonical version in
`preceptoros-web` → `odd/README.md`):

- `odd/tasks/<feature-name>.md` — one feature, one document, one name:
  objective, why, scope, constraints, checklist with stable IDs,
  verification evidence, log, next step. English, like every public
  artifact. No date in the file name.
- Landed features move to `odd/done/` with a `Status: landed` line;
  `odd/tasks/` holds only live work.
- Work-unit commits (~400 authored lines, advisory). Work never halts for a
  signature. Delivery gates are never skipped.
