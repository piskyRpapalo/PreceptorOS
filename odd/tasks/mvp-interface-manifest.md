# MVP-1 interface manifest: node builder

Inventory and status only, 2026-10-28. Scope: the user journey from the app acquisition door through the first fight against a node, and the node-builder doors that this commission opens. Each row has exactly one state: **LAW** is a merged house anchor, **ADAPT** is existing work still needing integration, **MISSING** names the smallest verifiable missing slice, and **DOOR** names a future capability without building it. LAW describes the named anchor, not proof that every related experience is complete or live.

Measured source snapshots: [web main `2270db3`](https://github.com/piskyRpapalo/preceptoros-web/tree/2270db32d1f46b18ed54fc8c1ab6389f022f78e3); [app main `a8a25c4`](https://github.com/piskyRpapalo/PreceptorOS/tree/a8a25c428d82fc0383eb1e9994af1f34663b684c). Live route checks below used `curl -sS -o /dev/null -w '%{http_code}'` on 2026-10-28; they measure HTTP status, not visual correctness or signature authority. Existing exact-head PRs are evidence of their own scope only.
