# Colony authoring: draft contract

The [decree](https://github.com/piskyRpapalo/preceptoros-web/pull/387#issuecomment-6470298863) makes the app the place where nodes are authored and linked. This slice proposes an in-memory draft only: unique node identities and axial cells, valid undirected links and a strict 1,024-byte ceiling. A separate function converts a supplied observation into a LIVE or STALE stamp with a cause. It performs no poll, authentication, freshness check, persistence, signing or publication; callers cannot treat the synthetic observation as evidence of liveness. An authoritative poll protocol, timeout and trust rules are NO_DATA until established.

Existing registration is a dry-run preview and the signed credential exporter is a separate explicit path. Neither is represented as a working shared map publishing workflow. The prior app screenshots are in [app #120](https://github.com/piskyRpapalo/PreceptorOS/pull/120); after screenshot is NO_DATA because this slice has no interface or rendered map. Live node and web/app parity claims are NO_DATA.

First motion measurement: NO_DATA. A connected Android device was observed, but no evidence established it as the weakest live device in the fleet ring; the global map's frame rate and principal-node fluidity were not measured.
