# Building service authoring contract

Commission: [the linking chatbot decree](https://github.com/piskyRpapalo/preceptoros-web/pull/387); app authors the source for the lower-panel catalogue. The existing `colony/core.js` checks the state rows and `colony/projection.js` maps the building's axial cell. A service is selected by its node, building and service keys. The building row must name that node; duplicate service matches are ambiguous. The result is a cause-bearing declared source and location, not a URL, invocation, model answer or proof that the source is live. A digest is a declared identifier, not authenticated provenance. Missing or invalid inputs fail to `NO_DATA` with cause. Individual service and result packets must be below 1,024 UTF-8 bytes.

The house mathematics in `docs/canon-house-maths.md` requires seals, bounded packets and judges; `docs/canon-map-panels.md` separates reading a place card from the human gesture that executes an action. `study/09-lore.md` describes the Stone Path as measured closes and resources as receipts. No reward amounts, distributions or completed interactions are invented by this contract. The chunk-router catalogue and actual source receipts are NO_DATA until another component supplies and verifies them. No user message, network request, storage, execution or reward is produced by resolving a route.

Before evidence: local app captures and map history in [app #120](https://github.com/piskyRpapalo/PreceptorOS/pull/120). After screenshot: NO_DATA, because this slice has no rendered interface. The visual comparison and weakest-device motion are not established by a pure contract. Real poll, liveness, source verification, shared catalogue, web integration and deployed behavior remain NO_DATA.

The judge is `node colony/service_cases.cjs`; `test_colony_services.py` executes it twice and is included in `bin/pruebas`. The red-before-green run failed because the implementation did not exist. Cases exercise an authorized fixture and reject missing nodes, missing or foreign buildings, ambiguous services, invalid source, missing cause, size overflow, invalid state and invalid query. Fixtures are synthetic; the digest does not assert a real service.
